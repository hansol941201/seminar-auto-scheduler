기존 직원 일정 연동 (예정)
회사에서 사용 중인 기존 직원 일정 달력과의 연동 방식은 아직 확정되지 않았습니다. 연동 전까지는 세미나 시스템 내 배정 일정만으로 자동배정·대타 계산을 수행합니다.

연동 시 아래 정보를 함께 계산하도록 데이터 구조가 이미 분리되어 있습니다 (externalStaffCalendar): 기존 일정 시간, 기존 일정 장소, 일정 종료시간, 다음 일정, 이동시간. 임의로 특정 캘린더 API를 연결하지 않았습니다.

실제 SMTP/이메일 발송 API 연동 전입니다. 아래 버튼은 브라우저의 기본 메일 프로그램(mailto)을 열어 초안을 준비하며, 최종 전송은 메일 프로그램에서 직접 눌러야 합니다. 서버에서 자동으로 발송하려면 사내 SMTP 또는 이메일 발송 API(예: SendGrid 등) 연동이 필요합니다.
